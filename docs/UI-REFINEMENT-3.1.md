# Workout 3.1 — ימים ואימון באותו מסך

החידוד נעשה בעקבות המשוב שהסיכום הראשי הסתיר את הימים, העיצוב הרגיש חשוך ועמוס, והמעבר בין סט למנוחה לא היה מספיק ברור.

## השינוי בחוויית השימוש

| לפני | עכשיו |
|---|---|
| דף סיכום, בחירת אימון ואז מסך תרגילים | ימים למעלה, בחירת אימון ותרגילים באותו מסך |
| כרטיס סיכום גדול לפני לוח השבוע | שורת סיכום קצרה; לוח השבוע גלוי ונשאר מעל אזור התרגילים |
| כמה כרטיסי תרגילים מלאים ופקדים חוזרים | כרטיס פעיל פתוח, שאר התרגילים מקוצרים עם סימוני התקדמות |
| לאחר התרגיל צריך לחפש את הבא | הסט האחרון סוגר את הכרטיס ופותח את התרגיל הבא שלא הושלם |
| הטיימר מציע לרשום סט כשהמנוחה מסתיימת | הטיימר מחזיר לסט הבא; מסמנים רק אחרי הביצוע בכרטיס התרגיל |
| פקדי תיקון חזרות בולטים תמיד בטיימר | תיקון זמין בלחיצה, לצד טיימר קצר וברור יותר |
| רקע כהה מאוד וניווט תחתון קבוע | ברירת מחדל בהירה, כרטיסים לבנים והיסטוריה/הגדרות בראש המסך |

הזרימה היא: **סיימתי סט → מנוחה → חזרה לסט הבא → ביצוע וסימון → השלמת התרגיל → התרגיל הבא**. בסיום כל התרגילים מופיעה פעולה אחת לשמירת האימון. ניתן גם לסיים אימון חלקי מכפתור הסיום ליד שעון האימון.

## מה נשמר במנוע

המנוע הקיים ממשיך להיות מקור האמת: פקודה דרך `WorkoutCoordinator`, עדכון אטומי, ערך ומשקל לכל סט, הגנה על פעולות כפולות ומועד סיום שמור לטיימר. פתיחת כרטיס או בחירת יום אינן רושמות סט ואינן משנות תאריך של ביצוע. הסט האחרון עדיין מסתיים ללא יצירת מנוחה מיותרת. ההתראה ברקע ממשיכה להציע רישום של סט שבוצע.

תיקון חזרות בזמן המנוחה מעדכן גם את הערך שמוצע בכרטיס לסט הבא. פעולות סימון תרגיל שלם, ניקוי וביטול נשארו זמינות. שפות, תזכורות, גיבויים, עריכת תוכנית והיסטוריה נשמרו.

העדכון מחיל את המראה הבהיר פעם אחת, ושומר את התוכנית, המשקלים, האימון הפעיל והטיימר. לאחר מכן אפשר לבחור כהה או מערכת בהגדרות, והבחירה נשמרת. מזהה האפליקציה ומפתח החתימה נשארו זהים ל־3.0, ולכן 3.1 מותקנת כעדכון לגרסה שנבנתה מחדש.

## בדיקות ממוקדות

- 47 בדיקות JVM של המנוע, התיאום ומעבר המראה עברו.
- ארבעה תהליכים באמולטור: ימים וסט ראשון גלויים ללא מעבר דף; פתיחת התרגיל הבא אחרי הסט האחרון; חזרה ממנוחה בלי רישום סט; אימון מלא עם ביטול והיסטוריה; וכן מעבר שפה/מראה ושחזור Activity עם הטיימר.
- בדיקה חזותית של המסך הראשי, הכרטיס הפעיל, הטיימר ופס הניווט של Android.
- בניית APK מסוג Release עם אותו מזהה אפליקציה וחתימה מקומית.

תוצאות התהליכים: [redesign-flows.txt](evidence/redesign-flows.txt). בדיקות אלו ממוקדות בשינוי, ואינן טענה שכל מכשיר פיזי נבדק.

ה־APK הסופי נבנה, חתימתו אומתה והוא הותקן בהצלחה באמולטור. עותק נמצא בשולחן העבודה בשם `Workout-3.1.0.apk`. נבדק גם שתיקון החזרות מ־10 ל־11 בטיימר מציג 11 בכרטיס הבא, ושהתוכן נשאר מעל פס המחוות של Android.

תצוגה בפועל: [מסך האימון](screenshots/workout-3.1.png) · [מנוחה שהסתיימה](screenshots/timer-3.1.png).

המקור `Workout-Tracker` נשאר ללא שינוי. ה־APK וקוד המקור של 3.0 נשמרו בתיקיית `dist` לצורך חזרה והשוואה. לא נעשה שינוי בבראנצ׳ים.
